Get it on this computer

Tip: if your phone and computer share the same account with calendar sync turned on, this will show up on your phone too.

Then paste it into your calendar app:

Mac (Apple Calendar): In Calendar, go to File → New Calendar Subscription, paste the link, and click Subscribe. Set "Auto-refresh" to something like every hour. For notifications, go to Calendar → Settings → Alerts and set a default alert time for subscribed calendars.

Windows (Outlook): Go to Calendar → Add calendar → Subscribe from web, and paste the link (in classic desktop Outlook: File → Account Settings → Internet Calendars → New). Outlook doesn't reliably send reminders for calendars added this way, so we'd suggest email reminders instead.

Google Calendar (any computer): On the web, click the + next to "Other calendars" in the left sidebar, choose "From URL," and paste it. Google Calendar doesn't support notifications at all for calendars added this way, so if this is how you use your calendar, email reminders are the only way to get a heads-up.

Not getting reminders? Turn on notifications for this calendar in your app's settings, or sign up for email reminders instead.
