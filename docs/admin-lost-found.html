Approve a Lost & Found Post

Clicking the link in the submission email brings you here with everything already filled in, just double-check it, then click "Prepare for GitHub". It'll open GitHub's own "create file" page, pre-filled with today's date stamped as the post date. Review it there and click Commit new file to publish. Nothing goes live until you click that button on GitHub (docs/lost-found.json regenerates automatically a few moments after that).

Pre-filled from a submission. Review the fields below, then continue.
Got a photo attached to the email? Upload it first: go to data/lost-found-photos/ on GitHub, "Add file → Upload files", drop the photo in, and commit it. Then type the exact filename you uploaded into "Photo filename" below before continuing. No photo? Just leave it blank.
To reject a submission, just don't do anything here: ignore or delete the email. Nothing is published unless you go through this form and commit the file on GitHub yourself.
