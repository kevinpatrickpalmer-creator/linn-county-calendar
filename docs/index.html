To check it worked, open your phone or computer's own calendar app. You should see events start showing up there within a minute or two. If nothing appears, make sure your calendar app finished adding the subscription (some ask you to confirm before it's actually added).

Not getting reminders? Subscribed calendars often don't have notifications turned on by default. Check your calendar app's alert settings for this calendar, or sign up for email reminders instead.

How to subscribe on a Windows PC or Mac, and turn on notifications

Mac (Apple Calendar): Click "Subscribe to Calendar" above. The Calendar app opens with an "Add Subscription" window. Set "Auto-refresh" to something like every hour, then click OK. For notifications, go to Calendar → Settings → Alerts and set a default alert time for subscribed calendars.

Windows (Outlook): Right-click "Download / copy link to subscribe" above and choose "Copy Link Address." In Outlook, go to Calendar → Add calendar → Subscribe from web, and paste the link (in classic desktop Outlook: File → Account Settings → Internet Calendars → New). Outlook doesn't reliably send reminders for calendars added this way, so we'd suggest email reminders below instead.

Google Calendar (any computer): Right-click "Download / copy link to subscribe" above and copy the link address. In Google Calendar on the web, click the + next to "Other calendars" in the left sidebar, choose "From URL," and paste it. Google Calendar doesn't support notifications at all for calendars added this way, so if this is how you use your calendar, email reminders below are the only way to get a heads-up.

Notification support varies a lot by calendar app, and several of them don't handle it well for subscribed calendars like this one. If you want something that reliably notifies you, sign up for email reminders, that always works regardless of which calendar app you use.
