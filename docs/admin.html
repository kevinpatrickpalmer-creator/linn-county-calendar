Approve a Submitted Event

Copy the details from the submission email into this form, then click "Prepare for GitHub". It'll open GitHub's own "create file" page, pre-filled — review it there and click Commit new file to publish. Nothing goes live until you click that button on GitHub.

To reject a submission, just don't do anything here — ignore or delete the email. Nothing is published unless you go through this form and commit the file on GitHub yourself.
